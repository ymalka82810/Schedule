# מנהל לוחות זמנים (Schedule)

אתר שמציג מערכת שבועית ללימודים או לעבודה, ובהמשך ינהל גם את הזמן הפנוי.

האתר החי: https://ymalka82810.github.io/Schedule/

## מצב הפרויקט

- [x] שלב 1: לוח שבועי (RTL, צבע לכל מקצוע, מצב בהיר וכהה, תצוגת יום בטלפון)
- [x] שלב 2: הוספה, עריכה ומחיקה של שיעורים מהלוח, בחירה במשבצות בחירה, צבע לכל שיעור, וגיבוי JSON
- [x] שלב 3: אירועים חד-פעמיים, וביטול שיעור בשבוע אחד
- [x] שלב 4: יעדים גמישים ושיבוץ אוטומטי בזמן הפנוי, עם הסבר לכל מפגש
- [ ] שלב 5: העלאת קובץ מערכת (התחלנו: קריאת PDF עם טבלה ושכבת טקסט, אשף "מי אני" שמסנן את הקבוצות שלי ומזהה התנגשויות, מסך בדיקה ועריכה עם הקובץ המקורי לצד הטיוטה, וייבוא גרסה מעודכנת שמראה מה השתנה ושומר על ההתאמות האישיות. נשאר OCR)

האתר פתוח לכולם. בלי התחברות זו סביבת בדיקה עם לוח ריק שנשמר רק בזיכרון. הבעלים נכנס עם קוד חד-פעמי למייל (Resend), והמערכת האישית שלו (`src/data/initial.ts`, המכינה להנדסה ומחשבים) נשמרת ב-Convex.

הרעיונות להמשך, ובמיוחד קריאת מערכת מקובץ PDF: [WISHLIST.md](WISHLIST.md)

כניסה עם קוד למייל (Resend) רק לבעלים, ושמירה בשרת Convex: [SETUP-AUTH.md](SETUP-AUTH.md)

## הרצה מקומית

```bash
npm install
npm run dev
npm test   # בדיקות הפענוח והאשף
```

## מבנה

- `src/types.ts` – מבנה הנתונים (Slot, Lesson, FixedEntry, ChoiceGroup, Goal, OneOffEvent)
- `src/data/initial.ts` – המערכת ההתחלתית
- `src/lib/` – זמן ותאריכים, העדפת ערכת הצבעים ב-localStorage, חישוב הבלוקים לציור
- `src/components/WeekGrid.tsx` – הלוח השבועי
- `src/components/LessonDialog.tsx` ו-`src/lib/edit.ts` – עריכה מהלוח וגיבוי
- `src/lib/plan.ts` – תכנון הזמן הפנוי: זמן פנוי, ניקוד לכל מקום אפשרי ושיבוץ היעדים
- `src/lib/diff.ts` – השוואה בין המערכת השמורה לגרסה חדשה מהקובץ
- `src/lib/pdf/` – קריאת קובץ PDF: `raw.ts` (מילים וקווים מהעמוד), `grid.ts` (טבלה ותאים ממוזגים), `parseCell.ts` ו-`parseSchedule.ts` (פענוח), `toSchedule.ts` (טיוטה למערכת), `whoami.ts` (אשף "מי אני": סינון קבוצות והתנגשויות), `__tests__/` (בדיקות)
- `src/components/ImportDialog.tsx` – מסך הייבוא: בחירת קובץ, טיוטה על הלוח ועריכה
- `convex/` – שרת Convex: כניסה עם קוד למייל ובדיקת המייל המורשה, ושמירת המערכת של הבעלים
- `src/auth/AuthRoot.tsx` – בחירה בין סביבת בדיקה (זיכרון) לבעלים (שרת)
- `src/index.css` – עיצוב וערכות הצבעים

כל דחיפה ל-`main` בונה ומפרסמת את האתר ל-GitHub Pages.
